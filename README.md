# Speak Website 

Speak Website is a modern web-based application built using React 19 and Vite. The application is designed with an interactive interface using Framer Motion for animation and Recharts for data visualization.

## Key Features

- **Modern Stack** — Uses React 19 and Vite for fast and optimal development performance.

- **Tailwind CSS v4** — Modern, responsive design with the latest CSS utilities.
- **Smooth Animations** — Interactive animations using Framer Motion.
- **Data Visualization** — Display interactive charts with Recharts.
- **Client-side Routing** — Reload-free navigation using React Router DOM v7.
- **Idle Detection** — `react-idle-timer` integration for user session management.

## Installation Instructions

Follow these steps to run the project on your local environment.

### 1. Prerequisites

Make sure you have installed:

- Node.js version 18 or later
- npm or yarn

---

### 2. Clone Repository

```bash
git clone https://github.com/fadillahrohman/speak.git
cd speak
```

---

### 3. Install Dependencies

Use npm or yarn to install all project dependencies:

```bash
npm install
```

---

### 4. Run Development Mode

Run the development server with the following command:

```bash
npm run dev
```

Once the server is running, open:

```txt
http://localhost:5173
```

in your browser.

---

### 5. Build for Production

To create an optimized production version:

```bash
npm run build
```
